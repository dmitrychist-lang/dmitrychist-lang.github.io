# EcoPrint Photo Studio — официальный сайт

Публичный информационный сайт программы EcoPrint Photo Studio: описание, демонстрационные скриншоты встроенного гайда и раздел скачивания.

**Опубликованная на GitHub версия:** 1.4.89 · **Open Beta**. Комплект **v1.4.90** подготовлен; сайт автоматически переключится на него после публикации обоих файлов в GitHub Releases.

**Важно:** этот репозиторий содержит только материалы веб-сайта. Исходный код самой программы, файлы лицензирования и приватные архивы здесь не публикуются.

## Размещение

GitHub Pages: `Settings` → `Pages` → `Deploy from a branch` → `main` → `/ (root)` → `Save`.

Адрес после публикации: https://dmitrychist-lang.github.io/

## Релизы

Релиз **v1.4.89** уже опубликован. Для перехода на подготовленный **v1.4.90** создать GitHub Release с тегом `v1.4.90`, отметить **pre-release (Open Beta)** и загрузить оба файла с точными именами:

- `EcoPrint_Photo_Studio_Setup_v1.4.90.exe`
- `EcoPrint_Photo_Studio_v1_4_90_WIN10_x64.zip`

[Описание изменений v1.4.90](releases/v1.4.90.md) содержит контрольные суммы SHA-256. **Не добавлять в публичный репозиторий исходники, файлы лицензирования, приватные архивы или MASTER HANDOFF.**

Сайт получает ссылки и счётчики скачиваний через публичный GitHub Releases API. Пока **оба** файла v1.4.90 не загружены, он продолжает предлагать работающие загрузки v1.4.89.

## О статусе программы

Программа находится в открытом бета-тестировании. Возможны ошибки и несовместимость отдельных функций с оборудованием или драйверами. Недостатки будут по возможности исправляться.

Сайт и изображения — публичные. Проект не является официальным продуктом Epson.

## Почему создана программа

EcoPrint Photo Studio первоначально разработана для собственных задач фотопечати вместо устаревшей Epson Easy Photo Print и неудобной для автора Epson Photo+. Программой могут пользоваться те, кому она подходит; остальные могут выбрать альтернативное ПО.

Пункт «Поблагодарить автора» в самой программе предусматривает **добровольную благодарность на любую сумму, выбранную пользователем**.

## Ограничения по бумаге

- Поддерживаемые форматы: **A3, A4, 10 × 15 см**.
- Типы фотобумаги: **глянцевая и матовая**.
- Новые форматы печати и типы бумаги добавляться не будут.
