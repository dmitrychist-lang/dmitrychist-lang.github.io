# EcoPrint Photo Studio — официальный сайт

Публичный информационный сайт программы EcoPrint Photo Studio: описание, демонстрационные скриншоты встроенного гайда и раздел скачивания.

**Текущая версия:** 1.4.89 · **Open Beta**.

**Важно:** этот репозиторий содержит только материалы веб-сайта. Исходный код самой программы, файлы лицензирования и приватные архивы здесь не публикуются.

## Размещение

GitHub Pages: `Settings` → `Pages` → `Deploy from a branch` → `main` → `/ (root)` → `Save`.

Адрес после публикации: https://dmitrychist-lang.github.io/

## Релизы

Для включения скачиваний и счётчиков создать GitHub Release с тегом `v1.4.89` и вложить **два** файла с точными именами:

- `EcoPrint_Photo_Studio_Setup_v1.4.89.exe`
- `EcoPrint_Photo_Studio_v1_4_89_WIN10_x64.zip`

Сайт получает URL файлов и их `download_count` из публичного GitHub Releases API. Пока релиз не создан, кнопки ведут к списку релизов без ложных счётчиков.

## О статусе программы

Программа находится в открытом бета-тестировании. Возможны ошибки и несовместимость отдельных функций с оборудованием или драйверами. Недостатки будут по возможности исправляться.
